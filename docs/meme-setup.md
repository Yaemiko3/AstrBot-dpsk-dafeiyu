# 表情包配置

## 导入

打开表情包管理器 → 设置中心 → 导入与备份 → 从压缩包导入。

选择 Windows「下载」文件夹中的 `astrbot-meme-official-01-20261031.zip`，确认导入。

## 绑定大肥鱼

1. 设置中心 → 使用规则 → 新增规则。
2. 匹配类型选择「指定人设」。
3. 人设目标填写大肥鱼实际使用的 ID，默认是 `dafeiyu_custom`。
4. 使用表情包选择「官方表情包1号」，点击「保存规则」。

只有一个人格时，直接修改「默认」规则也可以。

回群发送「@大肥鱼 发一个开心的表情包」测试。

## 添加自己的表情

图片放在 `assets/memes/`，按开心、疑惑、害羞等分类。在插件中新建表情包、上传图片，再绑定到大肥鱼。
